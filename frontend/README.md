# EndPoint — Frontend

React 19, Vite, Express, Monaco Editor, Lucide SVG. Интерфейс соискателя и работодателя
использует FastAPI из корня этой ветки. Исходный backend также доступен в endpoint-backend.

## Быстрый старт

```bash
# Сначала запустить backend по инструкции корневого README
cd frontend
cp .env.example .env
npm ci
npm run build
npm start
```

Сайт: http://127.0.0.1:3001. API_URL=http://127.0.0.1:8000.
Express проксирует API и WebSocket; не помещайте API-ключи в VITE_* или браузер.
Для разработки: npm run dev (порт Vite отображается в терминале).

## Страницы

| Роль | Разделы |
|---|---|
| Соискатель | Профиль/резюме, вакансии, практика, квалификация, задания компаний, чат |
| Работодатель | Соискатели, вакансии, конструктор, отклики/ATS, решения, хакатоны |
| Администратор | База знаний |

Приглашения, таймеры и результаты хранятся в backend. Алгоритмы проверяются Judge0;
GitHub-проекты — git-eval. Проверенные решения имеют отдельную вкладку. Фото загружаются
авторизованным PrivateImage; логотип компании можно загрузить в редакторе компании.

## Дизайн и демонстрационный режим

Общие цвета/темы в src/site.css и src/style.css. Общий выпадающий список — StyledSelect.
Иконки SVG из Lucide. Хакатоны — мок-страница: форма выбирает PDF до 10 МБ, но ничего
не отправляет и не сохраняет на сервере. Пополнение баланса — демонстрация без оплаты.

## Проверка и сборка

npm run build. Ручная проверка: вход обеими ролями, предложение → чат → тестовое → решение,
аватарки/логотипы, адаптация под телефон, светлая/тёмная темы. Backend интеграционные тесты
описаны в ../docs/ENDPOINT.md. Локальные screenshot/QA-артефакты не входят в Git.

## Развёртывание

См. ../docs/DEPLOYMENT.md. Backend и frontend запускаются отдельно; nginx/Caddy должен
проксировать Express и WebSocket. Закройте служебные порты и включите HTTPS.
